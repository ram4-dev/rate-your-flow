# Rate Your Flow launch video

The `RateYourFlowX` composition is a 27-second, 1080×1080 silent launch video for X. The render command normalizes the final H.264 file to limited-range `yuv420p` for broad social-platform compatibility.

```bash
npm install
npm run render
npm run poster
```

The composition is entirely frame-driven and self-contained. Its report uses explicitly labelled illustrative values; it contains no user session data.
